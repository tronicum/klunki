Datenschutzerklärung für Klunki

Stand: 8. November 2026

Klunki ist eine Spielesammlung für zwei Personen (z. B. 4 Gewinnt, Mühle, Quartett, Schiffe versenken) als App für iPhone, iPad und Android sowie als Web-App (PWA) im Browser. Diese Erklärung beschreibt, welche Daten dabei verarbeitet werden.

Kurz gesagt

  • Kein Konto, keine Anmeldung.
  • Keine Werbung, keine Analyse, kein Tracking, keine Absturzberichte an uns.
  • Keine Software-Bibliotheken von Drittanbietern, die Daten sammeln.
  • Wir betreiben keinen Server für das Spiel und erhalten keine Daten von dir, außer du schreibst uns eine E-Mail (z. B. um Zugang zur App-Beta anzufragen).

Was auf deinem Gerät gespeichert wird

Klunki speichert nur Einstellungen, und zwar ausschließlich lokal auf deinem Gerät (in der App bzw. im Speicher des Browsers für diese Website):

  • dein Spielername und die zuletzt verwendeten Namen für Spiele auf einem Gerät,
  • die gewählte Sprache,
  • die Adresse eines Relays, falls du eins eingetragen hast,
  • das zuletzt gewählte Quartett-Deck.

Diese Daten verlassen dein Gerät nicht (mit Ausnahme des Spielernamens, siehe unten). Du löschst sie, indem du die App deinstallierst bzw. die Website-Daten im Browser löschst. Die Web-App legt außerdem ihre eigenen Dateien im Browser-Cache ab, damit sie offline funktioniert.

Spielername

Den Namen gibst du selbst ein. In der App kann er mit dem Gerätenamen vorausgefüllt sein; du kannst ihn jederzeit ändern. Der Name wird nur bei einem Spiel über das Netzwerk an das Gerät deiner Mitspielerin bzw. deines Mitspielers übertragen, entweder direkt im lokalen Netzwerk oder über ein Relay (siehe unten). Wenn du in der App einen Raum im WLAN startest, werden dein Name und das gewählte Spiel im lokalen Netzwerk angekündigt (Bonjour/mDNS), damit andere Geräte den Raum finden. Das können alle Geräte in diesem Netzwerk sehen, solange dein Raum offen ist.

Spielen über das Netzwerk

Bei einem Netzwerkspiel tauschen die beiden Geräte Spielnachrichten aus: Spielernamen, Spielauswahl, Züge, eine zufällige Sitzungskennung zum Wiederverbinden und die App-Version (damit beide Geräte zueinander passen).

  • Direkt im lokalen Netzwerk: Die Geräte verbinden sich unmittelbar miteinander. Es ist kein Server beteiligt.
  • Über ein Relay: Ein Relay ist ein kleines Programm, das die Spielenden selbst betreiben, z. B. auf einem Computer im eigenen WLAN (klunki relay). Wir betreiben kein Relay. Das Relay verbindet zwei Geräte über einen kurzen Raumcode und leitet die Spielnachrichten nur weiter. Es speichert sie nicht und schreibt keine Protokolle (weder Nachrichteninhalte noch IP-Adressen noch Raumcodes). Technisch bedingt kennt es die IP-Adressen der verbundenen Geräte, solange die Verbindung besteht. Ein Raum wird gelöscht, wenn das Gerät, das ihn gestartet hat, ihn verlässt oder er 10 Minuten lang nicht benutzt wird. Nutzt du ein Relay, das jemand anderes betreibt, ist diese Person dafür verantwortlich.

Zugriff auf das lokale Netzwerk

Die App fragt nach Zugriff auf das lokale Netzwerk. Er wird nur verwendet, um Räume im WLAN zu finden und anzukündigen (Bonjour/mDNS) und um direkt mit dem anderen Gerät zu spielen. Für nichts anderes.

Kamera

Die App nutzt die Kamera nur, wenn du einen QR-Code scannst, um einem Raum beizutreten. Das Bild wird auf dem Gerät ausgewertet und weder gespeichert noch übertragen. Die Web-App nutzt die Kamera nicht.

Bewegungssensor

Den Bewegungssensor nutzt Klunki nur zum Würfeln durch Schütteln. Die Bewegung wird auf dem Gerät ausgewertet und weder gespeichert noch übertragen. Im Browser auf dem iPhone fragt der Browser vorher um Erlaubnis; „Schütteln zum Würfeln“ lässt sich in den Spieloptionen ausschalten.

Kartenfotos und Links

Die Fotos auf den Quartett-Karten stammen von Wikimedia Commons und sind in der App enthalten; die Bildnachweise stehen in der App. Zur Laufzeit wird nichts nachgeladen. Links zu Wikipedia, Wikimedia Commons oder Lizenztexten öffnen sich nur, wenn du sie antippst, in deinem Browser; dort gelten die Datenschutzregeln dieser Websites.

Web-App (PWA) und diese Website

Die Web-App und diese Seite sind statische Dateien, die über GitHub Pages ausgeliefert werden. Schriften und Programmteile sind enthalten und werden nicht von anderen Servern geladen. GitHub kann beim Abruf technische Daten wie deine IP-Adresse protokollieren; siehe die Datenschutzerklärung von GitHub. Wird die Web-App von einem Relay im eigenen Netzwerk ausgeliefert, ist GitHub nicht beteiligt.

Last updated: 8 November 2026

Klunki is a collection of two-player games (e.g. Four in a Row, Nine Men's Morris, Quartett and a battleship-style game) as an app for iPhone, iPad and Android and as a web app (PWA) in the browser. This policy explains which data is processed.

  • No account, no sign-in.

What is stored on your device

Klunki only stores settings, and only locally on your device (in the app, or in the browser's storage for this website):

  • your player name and the names last used for games on one device,
  • the chosen language,
  • the address of a relay, if you entered one,
  • the last chosen Quartett deck.

This data does not leave your device (except the player name, see below). You delete it by uninstalling the app or clearing the website data in your browser. The web app also keeps its own files in the browser cache so it works offline.

Player name

You type the name yourself. In the app it may be pre-filled with the device name; you can change it at any time. The name is only sent to the other player's device in a network game, either directly on the local network or through a relay (see below). When you start a room on the Wi-Fi in the app, your name and the chosen game are announced on the local network (Bonjour/mDNS) so other devices can find the room. Every device on that network can see this while your room is open.

Playing over the network

In a network game the two devices exchange game messages: player names, the game chosen, moves, a random session identifier for reconnecting, and the app version (so both devices are compatible).

  • Directly on the local network: the devices connect to each other. No server is involved.
  • Through a relay: a relay is a small program that the players run themselves, e.g. on a computer on their own Wi-Fi (klunki relay). We do not run a relay. The relay pairs two devices by a short room code and only passes the game messages on. It does not store them and writes no logs (no message contents, no IP addresses, no room codes). For technical reasons it knows the IP addresses of the connected devices while the connection is open. A room is deleted when the device that started it leaves or after 10 minutes without use. If you use a relay run by someone else, that person is responsible for it.

Local network access

The app asks for local network access. It is used only to find and announce rooms on the Wi-Fi (Bonjour/mDNS) and to play directly with the other device. Nothing else.

Camera

The app uses the camera only when you scan a QR code to join a room. The image is processed on the device and is neither stored nor sent anywhere. The web app does not use the camera.

Motion sensor

Klunki uses the motion sensor only for rolling the dice by shaking. The motion is processed on the device and is neither stored nor sent anywhere. In the browser on an iPhone, the browser asks for permission first; “Shake to roll” can be switched off in the game options.

Card photos and links

The photos on the Quartett cards come from Wikimedia Commons and are bundled with the app; the credits are shown in the app. Nothing is downloaded at runtime. Links to Wikipedia, Wikimedia Commons or licence texts open in your browser only when you tap them; those websites' privacy policies apply there.

Web app (PWA) and this website

The web app and this page are static files served by GitHub Pages. Fonts and code are bundled and are not loaded from other servers. GitHub may log technical data such as your IP address when you visit; see the GitHub General Privacy Statement. When the web app is served by a relay on your own network, GitHub is not involved.

We do not pass the address on to anyone else and send no advertising. We delete your request and the entries at Apple or Google when you ask us to, at the latest when the beta ends. Please have an adult send the request.
